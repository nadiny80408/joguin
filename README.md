# Crystal-Catcher
```
Esse jogo foi feito na semana acadêmica da UNIPAR, como um método para o estudo da linguagem C#
```

## Requirements
```
Unity editor -v 6000.6.8f1
Unity hub -v 4.0.2
```
## OBS
```
Abrir com "GameScene" e não Sample.
Mova-se com WASD ou com as setas cima, baixo, esquerda, direita
```
